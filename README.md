# Layaq Trading Journal Super App

An offline, English-language trading journal for Windows
with before/after HTF, MTF, and LTF screenshots.

## Version 2 Changes

- Improved Backup and Restore system.
- Daily performance graphs.
- Weekly performance graphs.
- Monthly performance graphs.
- Yearly performance graphs.
- All Time performance graphs.

## Chart Types

- Line Chart
- Bar Chart
- Area Chart

## Features

- Offline Trading Journal
- Trade History
- Realized Net P&L
- Win Rate
- Trading Statistics
- Before/After Screenshots
- HTF, MTF and LTF Analysis
- Backup and Restore
- Dark Mode

## Build Windows EXE

1. Upload app.py to GitHub.
2. Open the Actions tab.
3. Select Build Windows EXE.
4. Run the workflow.
5. Download the EXE from Artifacts.
